## What I've built

### 🛺 [Namma Yatri](https://github.com/nammayatri) — India's first zero-commission mobility platform
Founding engineer. Built for Android and iOS with React Native, Java and PureScript.
**5M+ downloads · 100M+ completed rides.** Owned the Subscriptions client that replaced per-ride commission, reaching 70% driver adoption, and built a client-side caching and request de-duplication layer that cut cold-start times on low-end Android devices.

### 🚕 Bharat Taxi — Cooperative ride-hailing driver app
Co-architected and shipped from scratch in React Native and TypeScript.
**25,000+ drivers at launch → 500,000+ drivers and 1M+ monthly rides within three months.** Built the DigiLocker and MoRTH document verification flow, which cut driver onboarding from hours to near-instant.

### 🏗️ Multi-tenant merchant app framework
A themed, config-driven React Native monorepo that generates **20+ production apps from a single codebase** at ~80% code reuse, with automated multi-flavour builds and Play Console releases. A new partner brand goes live without a separate codebase or release pipeline.

### 💪 [MuscleFit — Free Workouts](https://play.google.com/store/apps/details?id=com.muscle.fit)
Personal project. Tap a muscle group on an interactive male/female body map and get exercises that target it. Gesture-driven hit detection over layered SVG paths, offline-first exercise data, shared components across both body models. Live on the Play Store.
